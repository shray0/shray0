Couple cool projects :)

- [eGPU enclosure](https://github.com/shray0/egpu-enclosure) — Building my own eGPU enclosure, so that you can connect a desktop GPU to your shoddy laptop. Designing a custom Altium PCB that routes four PCIe lanes from the USB4 bridge’s M.2 interface to a full-size GPU slot and handles ATX slot power and reset sequencing.
- [ChefOST VidOSC](https://github.com/chefOST/vidosc/tree/shray/feat/multistate-vidosc/experiments/shray_multistate) — Built trainable architecture for predicting how an object change states in cooking videos. For example, the model would predict when a potato goes from peeled -> sliced -> fried in a cooking video.
- [CIFAR-10 robustness](https://github.com/shray0/adversarial-robustness-cifar10) — Neural Network robustness experiments over datasets. Introducing ways to mathematically mess up neural networks (adversarial attacks), and ways to defend against these mess ups (adversarial defense).
- [Quantum-guided pruning](https://github.com/shray0/quantum-neural-network-pruning) — Neural network pruning experiments on IBM quantum hardware. Introducing ways to find the best prune of a neural network way faster than classical methods.
